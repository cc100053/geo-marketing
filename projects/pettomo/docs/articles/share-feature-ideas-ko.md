# PetTomo 앱에서 기능 아이디어를 보낼 때 쓰면 좋은 내용

PetTomo는 커플, 가까운 친구, 가족, 작은 초대 그룹이 함께 쓰는 비공개 공유 가상 펫 앱입니다. 핵심 경험이 공유 방 안에서 이루어지기 때문에, 좋은 기능 아이디어는 구체적인 상황에서 출발합니다. 어떤 방에서 무엇을 하려고 했고, 어떤 변화가 있으면 펫 돌봄 루틴이 더 편해지는지 적는 것이 좋습니다.

PetTomo 1.2.0의 앱 내 What's New 문구는 사용자가 앱에서 직접 기능 아이디어를 보낼 수 있다고 안내합니다. 이 경로는 제품 아이디어에 적합하며, 긴급 계정 문제나 결제 문제를 보내는 곳은 아닙니다.

## 핵심 요약

- PetTomo는 초대 기반 비공개 공유 방, 함께 키우는 펫, 채팅, 사진 먹이 주기, 추억, 방 꾸미기, 펫 꾸미기를 지원합니다.
- 1.2.0 앱 내 업데이트 문구는 앱에서 직접 기능 아이디어를 보낼 수 있다고 설명합니다.
- 좋은 요청은 공유 방 상황, 원하는 동작, 도움이 되는 이유가 분명합니다.
- 비밀번호, 결제 정보, 민감한 개인정보는 기능 요청에 쓰지 않습니다.
- 계정, 결제, 탈퇴, 긴급 지원은 기능 아이디어가 아닌 적절한 지원 경로를 사용합니다.

## 어떤 아이디어가 PetTomo에 잘 맞을까

PetTomo는 공개 소셜 네트워크가 아닙니다. 기능 아이디어도 초대된 멤버가 공유 방에서 펫을 돌보고, 사진을 남기고, 방을 꾸미고, 가벼운 일상 루틴을 이어가는 경험에 맞는 것이 좋습니다.

예를 들면 다음과 같은 주제가 적합합니다.

- 공유 방 초대와 참가 흐름
- 사진 먹이 주기와 사진 표시
- 방 채팅, 답장, 반응, 메시지 가독성
- 추억과 갤러리 정리
- 가구, 배경, 장비 같은 방 꾸미기
- 여러 펫이 있는 방과 메인 펫 전환
- 멤버의 앱 업데이트나 호환성 안내

## 전달하기 쉬운 작성 방법

먼저 실제 사용 장면을 적습니다. 커플 방인지, 친구 방인지, 장거리 관계에서 매일 쓰는 방인지, 가족 방인지가 보이면 요청의 배경을 이해하기 쉽습니다.

다음 정보를 포함하면 좋습니다.

- 어떤 화면이나 기능을 쓰고 있었는지
- 방에 펫이 한 마리인지 여러 마리인지
- 모든 멤버에게 영향을 주는지, 내 화면에만 필요한지
- 사진, 채팅, 추억, 꾸미기, 펫 돌봄 중 무엇과 관련 있는지
- 변경 후 공유 방이 어떻게 더 쉬워지는지

긴 목록보다 몇 문장으로 구체적으로 쓴 요청이 더 읽기 쉽습니다.

## 넣지 않는 것이 좋은 내용

비밀번호, 계정의 민감한 정보, 결제 카드 정보, 다른 방 멤버가 공유를 예상하지 않은 개인 메시지는 쓰지 마세요. 특정 사진이나 채팅과 관련된 아이디어라면 내용을 그대로 붙여 넣기보다 상황을 설명하는 방식이 안전합니다.

또한 PetTomo가 관계 결과를 보장하거나 현실의 대화를 대신한다는 전제로 요청하지 않는 것이 좋습니다. PetTomo는 가볍고 즐거운 공유 루틴을 만드는 앱입니다.

## 자주 묻는 질문

### 공유 방 새 기능을 제안할 수 있나요?

네. PetTomo 1.2.0 앱 내 업데이트 문구는 앱에서 직접 기능 아이디어를 보낼 수 있다고 안내합니다.

### 오류나 결제 상담도 기능 요청으로 보내야 하나요?

기능 요청은 제품 아이디어에 적합합니다. 계정, 결제, 탈퇴, 긴급 지원은 알맞은 지원 경로를 사용하세요.

### 어떤 요청이 검토하기 쉬운가요?

공유 방에서의 상황, 하려고 했던 동작, 어떤 변화가 도움이 되는지 짧고 구체적으로 쓰면 이해하기 쉽습니다.

## 정리

PetTomo 기능 아이디어는 실제 비공개 공유 방 사용 경험에서 나올 때 가장 전달하기 좋습니다. 함께 펫을 돌보는 방식, 사진 먹이 주기, 채팅, 추억, 꾸미기, 여러 펫 루틴이 더 명확해지는 제안이라면 구체적인 상황과 함께 앱 내 경로로 보내 보세요.
